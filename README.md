# ⚡ 99% Can't Win

Think you have lightning-fast reflexes?

Take on increasingly difficult reaction challenges in this addictive browser game. Only the quickest players can survive!

## 🎮 How to Play

1. Press START GAME.
2. Wait for the green target.
3. Click the target before it disappears.
4. Each successful click makes the challenge faster.
5. Survive for 30 seconds and beat your high score!

## ✨ Features

- Fast-paced reaction gameplay
- Increasing difficulty
- 30-second challenge
- Personal best score tracking
- Sound effects
- Score sharing
- Mobile-friendly interface
- Desktop and mobile support
- No downloads required

## 🛠 Technologies

- HTML5
- CSS3
- JavaScript
- Local Storage API

## 🚀 Run the Game

Open index.html in your browser.
